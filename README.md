# Video Speed Master

一款轻量浏览器扩展，让你对任意网页上的视频、音频随心变速，并支持在切走标签页后让视频继续后台播放。

## 功能特性

- **无级变速**：0.07x – 16x 自由调节，不再受站点 2x 上限限制
- **快捷键调速**：`Shift + ]` 加速、`Shift + [` 减速、`Shift + \` 复位
- **强制模式**：自动抵抗站点把速度改回 1x 的行为
- **后台播放**：离开标签页 / 切到别的窗口时视频仍继续播放，不会自动暂停
- **作用范围**：可设为「全局」（对所有标签页生效）或「当前标签」（逐标签独立设置）
- **按站点记忆**：可记住每个网站上次的播放速度
- **屏显提示**：调速时显示当前倍速

## 安装

- **商店安装**：在 [Microsoft Edge 加载项商店](https://microsoftedge.microsoft.com/addons/detail/video-speed-master/dbglccpkplbaapakolhfcdnmejejnmnb) 一键安装「Video Speed Master」。
- **手动加载（开发人员模式）**：打开 `edge://extensions` → 开启「开发人员模式」→ 点击「加载解压缩的扩展」→ 选择本文件夹。

## 使用说明

1. 打开任意包含视频 / 音频的网页。
2. 点击工具栏图标，拖动滑块或输入倍速，也可直接使用快捷键。
3. 在「作用范围」中选择「全局」或「当前标签」：
   - **全局**：在任一标签调速，其它已打开的标签页同步生效。
   - **当前标签**：仅本标签生效，可逐标签单独设置。
4. 打开「后台播放」开关：开启后切走标签页视频仍继续播放；你手动按下的暂停不会被自动恢复。
5. 按需开关「强制模式」「记住本站点速度」「屏显提示」。

## 常见问题

- **调速不生效 / 被限速？**
  部分站点会在播放器内部反复重置速度，开启「强制模式」即可对抗。超过 2x 时，站点自带的速度菜单可能不显示同步，但变速已实际生效。
- **后台播放不生效？**
  确认已在 popup 中开启「后台播放」。极少数站点使用特殊的暂停检测方式，如仍不生效可反馈具体网址。
